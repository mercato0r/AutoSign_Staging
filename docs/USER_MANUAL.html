PANDUAN PENGGUNA AUTOSIGN PRO

Dokumentasi Pengoperasian dan Standar Prosedur Penandatanganan Dokumen PDF Massal

Versi Rilis 3.2.0 Edisi Dokumentasi: Oktober 2026

AutoSign Pro adalah perangkat lunak otomasi untuk penandatanganan dan pembubuhan stempel secara massal (batch processing) pada dokumen berformat PDF. Aplikasi ini dilengkapi dengan perancang tata letak visual (Visual Layout Designer), pengenalan kata kunci profil, eksekusi paralel multi-core, dan penempatan tanda tangan multi-halaman.

1. Persyaratan Sistem dan Persiapan Berkas

1.1 Persyaratan Sistem

  • Sistem Operasi: Windows 10 atau Windows 11 (arsitektur 64-bit).
  • Prosesor: Intel atau AMD multi-core (disarankan minimal 4 core untuk performa eksekusi paralel optimal).
  • Memori RAM: Minimal 4 GB (disarankan 8 GB atau lebih untuk pemrosesan dokumen beresolusi tinggi).
  • Penyimpanan: Minimal 500 MB untuk aplikasi dan berkas temporer, di luar kapasitas penyimpanan dokumen PDF.

1.2 Struktur Direktori yang Diperlukan

Sebelum menjalankan aplikasi, persiapkan tiga direktori utama pada media penyimpanan komputer:

  1. Folder PDF Master (Dokumen Sumber)
    Folder tempat menyimpan seluruh berkas PDF asli yang akan dibubuhi tanda tangan atau stempel. Folder ini dapat memiliki struktur subfolder bertingkat (misalnya berdasarkan divisi, tahun, atau nomor proyek).
  2. Folder Master Tanda Tangan (Signature Root)
    Folder tempat menyimpan seluruh berkas gambar tanda tangan, paraf, atau stempel. Berkas harus berformat PNG dengan latar belakang transparan. Nama berkas (tanpa ekstensi .png) harus sama persis dengan nama label yang ditentukan pada profil tata letak.
  3. Folder Output (Hasil Pemrosesan)
    Folder tujuan untuk menampung berkas PDF yang telah selesai diproses. Struktur subfolder dari Folder PDF Master akan diduplikasi secara otomatis ke dalam Folder Output.

2. Mekanisme Pencarian Berkas Tanda Tangan (3-Tier Resolver)

AutoSign Pro menerapkan algoritma pencarian hierarkis 3 tingkat untuk menemukan berkas gambar tanda tangan (.png) yang sesuai bagi setiap dokumen:

Tingkat Pencarian Mekanisme Kerja Contoh Jalur File
Tingkat 1: Subfolder Identik Sistem mencari berkas gambar pada subfolder di Master Tanda Tangan yang jalurnya identik dengan jalur subfolder dokumen PDF terhadap PDF Master. Master_TTD/Divisi_A/TTD_Manager.png untuk berkas PDF_Master/Divisi_A/Laporan.pdf.
Tingkat 2: Segmen Parent Terdekat (Reverse Walk) Jika berkas tidak ditemukan di tingkat 1, sistem memeriksa folder induk secara bertingkat dari subfolder terdalam hingga direktori di atasnya. Memeriksa Master_TTD/Proyek_X/TTD_Manager.png, lalu Master_TTD/Divisi_A/TTD_Manager.png.
Tingkat 3: Root Master Fallback Jika berkas belum ditemukan pada seluruh subfolder, sistem mengambil berkas tanda tangan umum yang berada langsung di direktori utama Master Tanda Tangan. Master_TTD/TTD_Manager.png.
Perhatian: Apabila setelah ketiga tingkat tersebut berkas gambar tanda tangan tidak ditemukan, sistem akan mencatat peringatan pada log dan melewati dokumen terkait untuk menjaga integritas data dokumen asli.

3. Panduan Penggunaan Visual Layout Designer

Visual Layout Designer digunakan untuk menentukan posisi, ukuran, dan target halaman bagi setiap tanda tangan atau stempel pada dokumen PDF secara visual dan akurat.

3.1 Membuka Layout Designer

  1. Pada jendela utama aplikasi, klik tombol Create New Profile untuk membuat profil baru, atau klik tombol Edit pada baris profil yang sudah ada.
  2. Jendela Layout Designer akan terbuka secara maksimal (maximized) untuk memudahkan penataan visual.

3.2 Memuat Berkas PDF Contoh

  1. Klik tombol Buka PDF Contoh pada panel bilah sisi kiri.
  2. Pilih salah satu berkas PDF yang mewakili format dokumen yang akan diproses secara massal.
  3. Halaman dokumen akan dirender pada lembar kerja kanvas di sebelah kanan.

3.3 Konfigurasi Identitas Profil

  • Profile Name: Masukkan nama profil yang unik dan deskriptif (misalnya Profil_Surat_Keputusan atau Profil_Kuitansi).
  • Keywords (Dipisahkan koma): Masukkan satu atau beberapa kata kunci pencocokan (misalnya SK, KEPUTUSAN, SURAT). Setiap berkas PDF di folder sumber yang memuat kata kunci tersebut pada nama berkasnya akan otomatis diproses menggunakan profil ini.

3.4 Navigasi Halaman Dokumen

Dokumen PDF dapat terdiri dari satu atau banyak halaman:

  • Gunakan tombol panah kiri [ < ] untuk berpindah ke halaman sebelumnya.
  • Gunakan tombol panah kanan [ > ] untuk berpindah ke halaman berikutnya.
  • Indikator halaman menampilkan informasi posisi halaman aktif saat ini (misalnya Hal: 1 / 5).
  • Setiap kotak tanda tangan yang ditambahkan akan terikat secara otomatis pada nomor halaman aktif saat kotak tersebut dibuat.

3.5 Manajemen Kotak Tanda Tangan (Bounding Box)

  • Menambah Kotak Baru: Klik tombol Kotak Baru pada sidebar. Kotak berwarna akan muncul di area tengah dokumen.
  • Menggeser Posisi Kotak: Arahkan kursor ke dalam area kotak, tekan dan tahan klik kiri mouse, lalu geser kotak ke posisi yang dituju.
  • Mengubah Ukuran Kotak (Resize): Klik pada kotak untuk mengaktifkannya. Pegangan sudut (resize handle) berbentuk persegi kecil akan muncul di sudut kanan bawah kotak. Tarik pegangan tersebut dengan klik kiri mouse untuk menyesuaikan ukuran.
  • Mengubah Label Kotak: Pilih kotak yang akan diubah, kemudian klik tombol Label. Masukkan nama label tanda tangan tanpa ekstensi .png (misalnya TTD_Direktur atau STEMPEL_LEMBAGA).
  • Menghapus Kotak: Pilih kotak yang ingin dihapus, kemudian klik tombol Hapus.

3.6 Navigasi Kanvas dan Kontrol Tampilan

  • Perbesaran Skala (Zoom In / Zoom Out): Klik tombol [ + ] untuk memperbesar atau tombol [ - ] untuk memperkecil. Anda juga dapat menggunakan pintasan cepat Ctrl + Scroll Roda Mouse. Sistem menerapkan mekanisme debouncing otomatis sehingga tampilan diperbarui secara halus tanpa lag.
  • Menggeser Lembar Kerja (Panning): Tekan dan tahan tombol Klik Kanan Mouse (Drag Button-3) di atas kanvas, lalu geser mouse ke arah yang diinginkan. Anda juga dapat menggunakan tombol klik tengah mouse (Button-2).
  • Pembatalan dan Pengulangan Aksi (Undo / Redo): Batalkan aksi terakhir menggunakan tombol Undo pada sidebar atau kombinasi tombol Ctrl + Z. Ulangi aksi yang dibatalkan dengan tombol Redo atau kombinasi Ctrl + Y / Ctrl + Shift + Z.
  • Tooltip Penjelasan: Arahkan kursor mouse ke tombol apa pun pada sidebar untuk membaca deskripsi singkat fungsi tombol tersebut.

3.7 Menyimpan Profil

Setelah penataan posisi selesai, klik tombol Simpan Profil di bagian bawah sidebar. Konfigurasi disimpan ke dalam berkas profiles/<Nama_Profil>.json. Jendela perancang dapat ditutup setelah dialog konfirmasi berhasil ditampilkan.

4. Panduan Eksekusi Pemrosesan Massal (Batch Processing)

4.1 Pemilihan Profil Aktif

  1. Pada bagian Profile Management di Jendela Utama, centang profil-profil yang ingin digunakan.
  2. Gunakan tombol Toggle All untuk memilih atau membatalkan pilihan seluruh profil sekaligus.
  3. Label penghitung menampilkan status profil yang dipilih (misalnya (2/3 Selected)).

4.2 Pengaturan Jalur Direktori (Path Configuration)

Tentukan ketiga jalur direktori kerja melalui tombol Browse:

  • PDF Root Folder: Direktori sumber dokumen PDF.
  • Signature Root: Direktori master gambar tanda tangan/stempel.
  • Output Folder: Direktori tujuan hasil pemrosesan.
Informasi: Seluruh konfigurasi direktori tersimpan secara otomatis pada berkas settings.json lokal sehingga tidak perlu dipilih ulang pada sesi kerja berikutnya.

4.3 Opsi Tambahan: Lewati Berkas yang Sudah Ada (Skip Existing)

Aktifkan opsi Skip Existing Files untuk efisiensi waktu. Apabila opsi ini aktif, dokumen PDF yang nama dan jalurnya sudah terdapat di folder output akan otomatis dilewati.

4.4 Menjalankan dan Menghentikan Proses

  • Menjalankan Proses: Klik tombol RUN PROCESS. Sistem akan memindai folder PDF sumber secara rekursif, mencocokkan kata kunci setiap dokumen dengan profil yang aktif, dan memproses dokumen menggunakan multi-threading.
  • Indikator Kemajuan: Batang kemajuan (Progress Bar) dan label status akan diperbarui secara teratur hingga proses selesai 100%.
  • Menghentikan Proses: Klik tombol STOP apabila ingin menghentikan antrean pemrosesan di tengah jalan. Sistem menghentikan tugas berikutnya dengan aman tanpa merusak berkas yang sedang ditulis.
  • Membuka Hasil: Klik tombol OPEN OUTPUT untuk membuka Folder Output secara langsung di Windows File Explorer setelah proses tuntas.

6. Pemecahan Masalah (Troubleshooting)

Gejala Masalah Penyebab Solusi Rekomendasi
Log menampilkan pesan:
MISSING: <label>.png		 Berkas gambar tanda tangan berformat PNG tidak ditemukan pada hierarki folder Master Tanda Tangan. Pastikan nama berkas gambar sama persis dengan nama label pada profil (huruf besar/kecil berpengaruh) dan berekstensi .png.
Pesan galat dokumen kosong atau rusak. Berkas PDF sumber memiliki ukuran 0 byte atau rusak saat proses pemindaian/unduhan. Buka berkas sumber dengan penampil PDF standar untuk memastikan keutuhan berkas. Ganti berkas jika rusak.
Halaman PDF memiliki rotasi (misal landscape ke portrait). Halaman dokumen memiliki rotasi internal bawaan (90, 180, atau 270 derajat). AutoSign Pro secara otomatis menghitung matriks derotasi sehingga posisi tanda tangan tetap tegak sesuai orientasi pembacaan.
Posisi tanda tangan bergeser dari letak seharusnya. Berkas PDF contoh memiliki ukuran halaman atau aspek rasio berbeda dari dokumen aktual. Gunakan berkas PDF contoh yang memiliki dimensi dan ukuran kertas yang identik dengan kelompok dokumen yang diproses.
